# ``TestKitOptions``

@Metadata {
    @DisplayName("SwiftTestKit and XCTestKit Options")
}

Configurable testing options.

## Overview

SwiftTestKit and XCTestKit share the same configurable options. The options 
are automatically available when importing either framework.

```swift
// Import options to use with SwiftTestKit.
import SwiftTestKit

// Import options to use with XCTestKit.
import XCTestKit
```

- Note: See specific framework documentation for additional usage information.
