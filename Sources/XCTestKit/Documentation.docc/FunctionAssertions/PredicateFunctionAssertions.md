# Predicate Function Assertions

Assert conditions over collections using predicates.

## Topics

### Tests for Satisfaction

- ``XCTKAssertAllSatisfy(_:_:_:fileID:file:line:column:options:)-func``
- ``XCTKAssertAnySatisfy(_:_:_:fileID:file:line:column:options:)-func``
- ``XCTKAssertNoneSatisfy(_:_:_:fileID:file:line:column:options:)-func``

### Tests for Granular Satisfaction

- ``XCTKAssertSatisfy(_:atLeast:_:_:fileID:file:line:column:options:)-func``
- ``XCTKAssertSatisfy(_:atMost:_:_:fileID:file:line:column:options:)-func``
- ``XCTKAssertSatisfy(_:range:_:_:fileID:file:line:column:options:)-func``
- ``XCTKAssertExactly(_:count:_:_:fileID:file:line:column:options:)-func``
- ``XCTKAssertExactlyOne(_:_:_:fileID:file:line:column:options:)-func``

### Tests for Ordering

- ``XCTKAssertSorted(_:by:_:fileID:file:line:column:options:)-func``

### Tests for Uniqueness

- ``XCTKAssertUnique(_:_:fileID:file:line:column:options:)-func``
- ``XCTKAssertUnique(_:by:_:fileID:file:line:column:options:)-func``
