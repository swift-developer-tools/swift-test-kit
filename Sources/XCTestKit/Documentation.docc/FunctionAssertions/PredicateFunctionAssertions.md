# Predicate Function Assertions

Assert conditions over collections using predicates.

## Topics

### Tests for Satisfaction

- ``XCTKAssertAllSatisfy(_:_:_:file:line:options:)-func``
- ``XCTKAssertAnySatisfy(_:_:_:file:line:options:)-func``
- ``XCTKAssertNoneSatisfy(_:_:_:file:line:options:)-func``

### Tests for Granular Satisfaction

- ``XCTKAssertSatisfy(_:atLeast:_:_:file:line:options:)-func``
- ``XCTKAssertSatisfy(_:atMost:_:_:file:line:options:)-func``
- ``XCTKAssertSatisfy(_:range:_:_:file:line:options:)-func``
- ``XCTKAssertExactly(_:count:_:_:file:line:options:)-func``
- ``XCTKAssertExactlyOne(_:_:_:file:line:options:)-func``

### Tests for Ordering

- ``XCTKAssertSorted(_:by:_:file:line:options:)-func``

### Tests for Uniqueness

- ``XCTKAssertUnique(_:_:file:line:options:)-func``
