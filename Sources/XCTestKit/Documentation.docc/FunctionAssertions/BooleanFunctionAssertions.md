# Boolean Function Assertions

Assert that a condition generates a true or false result.

## Topics

### Tests for True Conditions

- ``XCTKAssert(_:_:fileID:file:line:column:options:)-func``
- ``XCTKAssertTrue(_:_:fileID:file:line:column:options:)-func``

### Tests for False Conditions

- ``XCTKAssertFalse(_:_:fileID:file:line:column:options:)-func``
