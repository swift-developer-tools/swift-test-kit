# Equality and Inequality Function Assertions

Assert whether two values are equal or unequal.

## Topics

### Tests for Equality and Inequality

- ``XCTKAssertEqual(_:_:_:file:line:options:)-func``
- ``XCTKAssertNotEqual(_:_:_:file:line:options:)-func``

### Tests for Identical Objects

- ``XCTKAssertIdentical(_:_:_:file:line:options:)-func``
- ``XCTKAssertNotIdentical(_:_:_:file:line:options:)-func``

### Tests for Equality Within a Specified Accuracy

- ``XCTKAssertEqual(_:_:accuracy:_:file:line:options:)-726jt``
- ``XCTKAssertEqual(_:_:accuracy:_:file:line:options:)-2b7lc``
- ``XCTKAssertNotEqual(_:_:accuracy:_:file:line:options:)-311uy``
- ``XCTKAssertNotEqual(_:_:accuracy:_:file:line:options:)-5py3y``
