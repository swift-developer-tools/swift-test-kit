# Equality and Inequality Function Assertions

Assert whether two values are equal or unequal.

## Topics

### Tests for Equality and Inequality

- ``XCTKAssertEqual(_:_:_:fileID:file:line:column:options:)-func``
- ``XCTKAssertNotEqual(_:_:_:fileID:file:line:column:options:)-func``

### Tests for Identical Objects

- ``XCTKAssertIdentical(_:_:_:fileID:file:line:column:options:)-func``
- ``XCTKAssertNotIdentical(_:_:_:fileID:file:line:column:options:)-func``

### Tests for Equality Within a Specified Accuracy

- ``XCTKAssertEqual(_:_:accuracy:_:fileID:file:line:column:options:)-1irtq``
- ``XCTKAssertEqual(_:_:accuracy:_:fileID:file:line:column:options:)-5d105``
- ``XCTKAssertNotEqual(_:_:accuracy:_:fileID:file:line:column:options:)-1puup``
- ``XCTKAssertNotEqual(_:_:accuracy:_:fileID:file:line:column:options:)-29qr5``
