# Equality and Inequality Macro Assertions

Assert whether two values are equal or unequal.

## Topics

### Tests for Equality and Inequality

- ``XCTKAssertEqual(_:_:_:file:line:options:)-macro``
- ``XCTKAssertNotEqual(_:_:_:file:line:options:)-macro``

### Tests for Identical Objects

- ``XCTKAssertIdentical(_:_:_:file:line:options:)-macro``
- ``XCTKAssertNotIdentical(_:_:_:file:line:options:)-macro``

### Tests for Equality Within a Specified Accuracy

- ``XCTKAssertEqual(_:_:accuracy:_:file:line:options:)-61xtk``
- ``XCTKAssertEqual(_:_:accuracy:_:file:line:options:)-ewtn``
- ``XCTKAssertNotEqual(_:_:accuracy:_:file:line:options:)-130t8``
- ``XCTKAssertNotEqual(_:_:accuracy:_:file:line:options:)-5kbsz``
