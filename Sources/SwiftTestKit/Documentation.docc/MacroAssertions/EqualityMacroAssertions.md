# Equality and Inequality Macro Assertions

Assert whether two values are equal or unequal.

## Topics

### Tests for Equality and Inequality

- ``STKAssertEqual(_:_:_:fileID:file:line:column:options:)-macro``
- ``STKAssertNotEqual(_:_:_:fileID:file:line:column:options:)-macro``

### Tests for Identical Objects

- ``STKAssertIdentical(_:_:_:fileID:file:line:column:options:)-macro``
- ``STKAssertNotIdentical(_:_:_:fileID:file:line:column:options:)-macro``

### Tests for Equality Within a Specified Accuracy

- ``STKAssertEqual(_:_:accuracy:_:fileID:file:line:column:options:)-7q89n``
- ``STKAssertEqual(_:_:accuracy:_:fileID:file:line:column:options:)-41pek``
- ``STKAssertNotEqual(_:_:accuracy:_:fileID:file:line:column:options:)-5talz``
- ``STKAssertNotEqual(_:_:accuracy:_:fileID:file:line:column:options:)-1otmk``
