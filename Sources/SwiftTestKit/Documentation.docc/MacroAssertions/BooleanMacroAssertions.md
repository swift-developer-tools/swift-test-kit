# Boolean Macro Assertions

Assert that a condition generates a true or false result.

## Topics

### Tests for True Conditions

- ``STKAssert(_:_:fileID:file:line:column:options:)-macro``
- ``STKAssertTrue(_:_:fileID:file:line:column:options:)-macro``

### Tests for False Conditions

- ``STKAssertFalse(_:_:fileID:file:line:column:options:)-macro``
