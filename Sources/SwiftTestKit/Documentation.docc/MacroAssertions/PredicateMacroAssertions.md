# Predicate Macro Assertions

Assert conditions over collections using predicates.

## Topics

### Tests for Satisfaction

- ``STKAssertAllSatisfy(_:_:_:fileID:file:line:column:options:)-macro``
- ``STKAssertAnySatisfy(_:_:_:fileID:file:line:column:options:)-macro``
- ``STKAssertNoneSatisfy(_:_:_:fileID:file:line:column:options:)-macro``

### Tests for Granular Satisfaction

- ``STKAssertSatisfy(_:atLeast:_:_:fileID:file:line:column:options:)-macro``
- ``STKAssertSatisfy(_:atMost:_:_:fileID:file:line:column:options:)-macro``
- ``STKAssertSatisfy(_:range:_:_:fileID:file:line:column:options:)-macro``
- ``STKAssertExactly(_:count:_:_:fileID:file:line:column:options:)-macro``
- ``STKAssertExactlyOne(_:_:_:fileID:file:line:column:options:)-macro``

### Tests for Ordering

- ``STKAssertSorted(_:by:_:fileID:file:line:column:options:)-macro``

### Tests for Uniqueness

- ``STKAssertUnique(_:_:fileID:file:line:column:options:)-macro``
- ``STKAssertUnique(_:by:_:fileID:file:line:column:options:)-macro``
