# Equality and Inequality Function Assertions

Assert whether two values are equal or unequal.

## Topics

### Tests for Equality and Inequality

- ``STKAssertEqual(_:_:_:fileID:file:line:column:options:)-func``
- ``STKAssertNotEqual(_:_:_:fileID:file:line:column:options:)-func``

### Tests for Identical Objects

- ``STKAssertIdentical(_:_:_:fileID:file:line:column:options:)-func``
- ``STKAssertNotIdentical(_:_:_:fileID:file:line:column:options:)-func``

### Tests for Equality Within a Specified Accuracy

- ``STKAssertEqual(_:_:accuracy:_:fileID:file:line:column:options:)-1lxew``
- ``STKAssertEqual(_:_:accuracy:_:fileID:file:line:column:options:)-6cwdd``
- ``STKAssertNotEqual(_:_:accuracy:_:fileID:file:line:column:options:)-3rmi7``
- ``STKAssertNotEqual(_:_:accuracy:_:fileID:file:line:column:options:)-59sds``
