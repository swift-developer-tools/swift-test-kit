# Boolean Function Assertions

Assert that a condition generates a true or false result.

## Topics

### Tests for True Conditions

- ``STKAssert(_:_:fileID:file:line:column:options:)-func``
- ``STKAssertTrue(_:_:fileID:file:line:column:options:)-func``

### Tests for False Conditions

- ``STKAssertFalse(_:_:fileID:file:line:column:options:)-func``
